## 💬 Chat Application (СВЯЗЬ 🤙 | INTOUCH 🤙 )

Веб-приложение для обмена сообщениями в реальном времени, упрощенный аналог Slack, Mattermost. Пользователи могут создавать каналы, отправлять сообщения, управлять каналами (создание, переименование, удаление). Приложение использует WebSocket для мгновенной доставки сообщений и Redux для управления состоянием. Интерфейс построен на Bootstrap 5, локализация реализована через `i18next` (русский язык по умолчанию).

## ✨ Features

- **Аутентификация**: регистрация и вход в систему с валидацией форм
- **Управление каналами**:
  - создание новых каналов
  - переименование существующих каналов
  - удаление каналов
- **Обмен сообщениями в реальном времени** через WebSocket:
  - отправка сообщений в выбранный канал
  - автоматическое получение новых сообщений без перезагрузки страницы
  - отображение имени пользователя
- **Фильтрация нецензурной лексики** в сообщениях и названиях каналов
- **Управление UI состоянием**: модальные окна, уведомления, загрузка
- **Локализация**: поддержка русского и английского языков
- **Обработка ошибок**: уведомления об ошибках сети, валидации и других проблемах

## 🧱 Project Architecture

Проект организован по принципу Feature-Sliced Design:

### Структура папок:

- `src/main.jsx` — точка входа, инициализация приложения, провайдеры (Redux, Router, Rollbar)
- `src/app/` — конфигурация приложения:

  - `api/baseApi.js` — базовый API клиент (RTK Query)
  - `model/store.js` — Redux store
  - `model/uiSlice.js` — состояние UI (модальные окна, активный канал)
  - `ui/App.jsx` — корневой компонент приложения
  - `i18n.js` — конфигурация локализации

- `src/pages/` — страницы приложения:

  - `LoginPage/` — страница входа
  - `SignUpPage/` — страница регистрации
  - `MainPage/` — главная страница с чатом
  - `NotFoundPage/` — страница 404

- `src/features/` — функциональные модули:

  - `auth/` — аутентификация:
    - `api/` — API для логина и регистрации
    - `model/` — Redux slice и схемы валидации
    - `ui/` — формы входа и регистрации
  - `channels/` — управление каналами:
    - `api/` — API для работы с каналами
    - `model/` — схемы данных каналов
    - `ui/` — список каналов, модальные окна (добавление, переименование, удаление)
  - `messages/` — сообщения:
    - `api/` — API для отправки сообщений
    - `ui/` — список сообщений, форма отправки

- `src/common/` — общие компоненты и утилиты:

  - `components/` — переиспользуемые компоненты (Header, Loader, Modal, Toast и др.)
  - `hooks/` — кастомные хуки (селекторы, скролл)
  - `layouts/` — макеты страниц
  - `routing/` — конфигурация маршрутов
  - `services/` — сервисы (WebSocket, фильтрация нецензурной лексики)

- `src/assets/` — статические ресурсы:

  - `locales/` — файлы локализации (ru.js, en.js)
  - `lootie/` — JSON анимации

- `vite.config.js` — конфигурация Vite с прокси для API и WebSocket

## 🔄 Workflow

1. **Аутентификация**: пользователь регистрируется или входит в систему
2. **Подключение к WebSocket**: после успешной аутентификации устанавливается соединение через Socket.io
3. **Загрузка данных**: через RTK Query загружаются каналы и сообщения
4. **Выбор канала**: пользователь выбирает канал из списка
5. **Отправка сообщений**: сообщения отправляются через API и автоматически появляются у всех пользователей через WebSocket
6. **Управление каналами**: создание, переименование и удаление каналов через модальные окна
7. **Фильтрация**: все сообщения проходят через фильтр нецензурной лексики перед отправкой

## ⚠️ Error Handling and Statuses

- **Валидация форм**: проверка длины имени пользователя (3-20 символов), пароля (минимум 6 символов), совпадения паролей
- **Ошибки аутентификации**: неверные учетные данные, пользователь уже существует
- **Ошибки сети**: проблемы с подключением к серверу
- **Ошибки каналов**: канал уже существует, ошибки при создании/удалении/переименовании
- **Ошибки сообщений**: проблемы при отправке сообщений

Все ошибки отображаются через `react-toastify` с локализованными сообщениями.

## 📝 Implementation Notes

- **WebSocket**: используется Socket.io для двусторонней связи в реальном времени
- **State Management**: Redux Toolkit с RTK Query для синхронизации с сервером
- **Валидация**: Formik + Yup для валидации форм на клиенте
- **Фильтрация**: библиотека `leo-profanity` для фильтрации нецензурной лексики (русский словарь)
- **Локализация**: автоматическое определение языка браузера, переключение между русским и английским
- **Мониторинг**: интеграция с Rollbar для отслеживания ошибок в продакшене
- **Прокси**: Vite проксирует запросы к API и WebSocket для разработки
